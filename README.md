# gilbyy

A driving game at gilbyy.com. You load the site and drive a 4x4 around a low-poly
valley, in the spirit of _Over the Hill_. That's it — it isn't a menu or a launcher,
and it doesn't link anywhere.

three.js for rendering, our own physics, no game engine, no backend, no auth.
